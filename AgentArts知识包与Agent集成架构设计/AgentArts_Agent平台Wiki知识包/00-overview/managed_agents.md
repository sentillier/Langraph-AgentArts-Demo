# Managed Agents（全托管智能体）

> 事实来源：`AgentArts原始材料-0916/智果（AgentArts）智能体平台 Managed Agents.pdf`（文档版本 01，2026-09-16）；对照 `API参考.pdf` 4.7（智能体运行时）、`产品介绍.pdf` 4「基本概念」。
>
> **Managed Agents 是 0916 材料新增的第三种开发范式**，0804 材料中不存在。它需要提交工单申请后方可使用。

## 1. 三种开发范式对比

| 维度 | 低代码开发 | 高代码开发 | **Managed Agents** |
| --- | --- | --- | --- |
| 核心定位 | 可视化编排智能体应用 | 用 SDK 编程构建智能体 | 表单化声明 + 全托管运行智能体 |
| 工作方式 | 拖拽画布、流程编排 | 写代码（Runtime / Tools / Memory / Gateway SDK、CLI） | 填表单配置，模型自主规划执行 |
| 目标用户 | 业务人员、低代码开发者 | 专业开发者、平台工程师 | 需要快速上线通用 Agent 并做企业级治理的团队 |
| 交付物 | 应用配置 | **容器镜像** | **配置项（无镜像）** |
| 运行底座 | 平台工作流引擎 | 运行时（用户管理版本/实例） | 全托管环境（平台托管） |
| 定制灵活度 | 通过节点/插件组合 | 代码层面完全可控 | 通过配置项调整 |

一句话边界：**Managed Agents 解决「不想打镜像、不想管基础设施」；运行时解决「代码要完全可控、要自定义依赖」**。

## 2. 核心概念

| 概念 | 定义 | 关键约束 |
| --- | --- | --- |
| **智能体（Agent）** | 定义"做什么"：模型、系统提示词、运行环境、工具与技能。支持版本管理，创建/更新均产生新版本 | 每租户 1,000 个；名称 `agent*` 开头，2–40 字符，小写字母/数字/中划线，创建后不可编辑 |
| **环境（Environment）** | 定义"哪里运行"：入站网关、出网网络配置、会话存储。**被智能体关联后禁止修改** | 每租户 1,000 个；名称 `environment*` 开头，规则同上；一个环境可被多个智能体引用 |
| **委托（Agency）** | 智能体运行所需的云资源访问授权 | 见 [05-identity](../05-identity/identity.md) |
| **Skill** | 从技能库选择挂载到智能体的技能包 | 见第 5 节 |
| **会话（Session）** | 一次完整的交互上下文，由调用方指定会话 ID | 英文/数字/`-`/`_`，≤ 64 字符 |

工作流程：**创建环境 → 创建智能体（关联环境）→ 通过 API 调用 → 发送请求获取响应 → 干预或中断 → 在"版本"/"日志"页签查看演进与运行日志**。

## 3. 环境（Environment）

### 3.1 出网网络配置

沙箱向外发起网络请求的能力，是**基础设施层的安全边界，优先级高于系统提示词与工具权限**——即使提示词被注入攻击，网络层仍可拦截非法访问。

> 出网网络配置在**环境创建后不可编辑**。

| 模式 | 说明 |
| --- | --- |
| 公网访问 | 通过互联网出口访问公网服务。**公网访问时，智能体不支持添加 Skill** |
| 私网访问 | 打通企业私有 VPC 内网，只能访问内网资源，流量不经过互联网 |

### 3.2 存储配置

用于将外部存储挂载到运行时沙箱容器，实现数据持久化、文件共享与会话状态保存。挂载由 **Miracle 沙箱平台**自动完成，无需自定义挂载代码或特权容器。

- `storageConfig` → Miracle `CreateTemplateStorageConfig`（承载 SFS Turbo 与 OBS）
- `sessionStorageConfig` → 独立字段（承载会话存储）

| 存储类型 | 文件特征 | 读写特征 | 性能 | 典型场景 | 最大数量 | 网络要求 |
| --- | --- | --- | --- | --- | --- | --- |
| **SFS Turbo** | 适量中大文件 | 读写混合、多实例共享 | 中等 IOPS、适中时延 | 模型文件、共享数据集、配置文件 | 5 个 | 私网（VPC） |
| **会话存储** | 会话级小文件 | 按会话隔离读写 | 低时延、按会话隔离 | 多轮对话上下文、会话临时数据 | 1 个 | 无限制 |
| **OBS** | 海量大文件 | 读多写少 | 高吞吐、低成本 | 用户上传文件、生成结果文件 | 10 个（最多 5 个桶） | 私网（VPC） |

**选择建议**：模型文件/共享数据 → SFS Turbo；会话上下文持久化 → 会话存储；用户上传/生成文件 → OBS。

**版本更新时的配置继承（增量修改）**：
- 未指定某存储子配置（如 `sfsTurbo` 为 `null`）→ 继承上一版本完整配置
- 指定了某存储子配置 → 用新配置替换旧配置（整体替换，非合并）
- 会话存储支持**字段级继承**：未指定字段（如 `uid`）继承上一版本该字段值

**使用约束（必须在设计中消化）**：
- SFS Turbo 与 OBS **仅在私网访问（VPC 网络模式）下支持配置**
- 所有挂载路径不能包含 `..`（防路径穿越）；挂载路径须为 `/home`、`/mnt`、`/data`、`/tmp` 及其子目录，最大 4000 字符
- 多个挂载（OBS / SFS Turbo / 会话存储之间）**禁止使用相同或存在包含关系的路径**
- 会话存储配置后**不支持取消**，仅支持修改挂载路径
- 会话存储底层基于 OBS（FUSE 挂载），`umask` 在挂载时决定权限，运行时 `chmod`/`chown` **不生效**
- SFS Turbo 需为 NFS 协议，且与运行时出网配置在**同一 VPC**；安全组需放通 NFS 端口；挂载为 **hard 模式**
- OBS 挂载需为运行时委托配置 OBS 权限：只读需 `obs:bucket:headBucket`、`obs:bucket:listBucket`、`obs:object:getObject`；读写再加 `obs:object:putObject`、`obs:object:deleteObject`
- OBS 采用**回写模式（write-back）**：应用先与 FUSE 交互，`write()` 只写本地临时文件，`close()` 时才真正上传。**进程崩溃 / 断电 / `kill -9` 会导致未关闭文件的数据永久丢失**；100GB 文件的 `close()` 可能需数分钟。建议：关键数据写入后检查 `close()` 返回值、对持久性要求高的场景定期 `fsync()`、必要时启用 `use_cache`

## 4. 智能体配置

| 配置块 | 内容 |
| --- | --- |
| 基本信息 | 名称、描述、**运行环境**、入站身份认证 |
| 模型 | 系统预置 `HuaweiCloudMaaS/GLM-5.2`，免费使用；也支持自定义模型接入 |
| 提示词 | 底层规则 / 身份 / 能力 / 约束 / 输出格式，平台给出标准结构：身份 → 目标 → 能力 → 禁止 → 执行规则 → 输出格式 |
| 内置工具 | 见 4.1 |
| Skill | 见第 5 节 |
| 可观测配置 | 日志是否上报 LTS。**默认已开启**；未开启则运行日志无法上报云日志服务（LTS），日志管理按需收费 |
| 高级配置 | 生命周期：会话空闲超时、最大存活时间 |

### 4.1 内置工具

| 工具名 | 描述 |
| --- | --- |
| `*` | 包含所有命令，可在会话中执行 bash 命令或文件操作 |
| `bash` | 在会话中执行 bash 命令 |
| `read_file` | 读取文本、图片、PDF、Jupyter Notebook、Office 文档 |
| `write_file` | 写入文件内容（覆盖式） |
| `edit_file` | 精确字符串替换编辑已有文件 |
| `glob` | 使用 glob 模式查找文件 |
| `list_files` | 列出目录内容 |
| `grep` | 在文件中搜索内容，支持正则表达式 |

### 4.2 生命周期（高级配置）

| 参数 | 含义 | 取值范围 | 默认值 |
| --- | --- | --- | --- |
| 会话空闲超时 | 一段时间无用户交互时自动结束会话并释放运行资源。超时后会话终止，再次调用需重新发起 | 1 ~ 10,080 分钟 | 15 分钟 |
| 最大存活时间 | 会话从创建起能存活的绝对上限，无论期间是否有交互，到时强制结束 | 1 ~ 168 小时 | 24 小时 |

使用建议：不确定时先用默认 15 分钟；最大存活时间按任务最长耗时设置并留余量。

## 5. Skill

### 5.1 来源与类型

- Skill 来自 AgentArts **"我的资产 > Skill"** 中的技能
- 支持用户手动上传的技能，仅限个人使用
- 也支持导入第三方工具生成的资源包，或存储在 **OBS** 中的资源包
- 平台提供精选 Skill，覆盖通用、效率提升、自动化工具、设计与可视化、内容创作等领域

> 第三方技能来源于第三方服务商，AgentArts 不对其做任何形式的保证，使用前需审慎评估风险并遵守第三方协议。

### 5.2 目录结构与按需加载

| 组成部分 | 必需 | 作用 |
| --- | --- | --- |
| `SKILL.md` | **必需** | 核心元数据与使用说明书：Skill 名称、用途、操作指南。智能体启动时优先加载其元数据，用于判断是否调用及如何调用 |
| `scripts/` | 可选 | 可执行代码文件，完成具体计算任务，保证确定性与可重复性 |
| `references/` | 可选 | 参考资料：第三方 API 文档、设计规范、测试报告等 |
| `assets/` | 可选 | 静态资源与模板：配置模板、音视频文件等 |

加载机制：智能体在对话过程中**动态判断哪些 Skill 与当前任务相关，仅加载完成任务所需的必要信息**，避免上下文窗口过载。

### 5.3 约束

- **使用技能需满足：接入的环境为私网访问且挂载了 OBS**
- 与"公网访问不支持 Skill"是同一条约束的两面，设计环境时必须先确认 Skill 需求

## 6. 调用智能体

### 6.1 协议与端点

通过 **WebSocket** 与 Managed Agents 后端交互，平台全托管智能体循环、沙箱编排与工具执行层：

```
ws://{endpoint}/runtimes/{runtime_name}/ws
```

调用参数：`--url`（WS 端点）、`--auth "Bearer {api_key}"`、`--session-id {会话ID}`、`--message {内容}`。

### 6.2 认证方式

智能体支持 **IAM 认证、OAuth 2.0 认证、API Key 认证**三种。创建智能体时配置入站身份认证，调用方需按所配置方式完成验证。

| 认证方式 | 凭据获取路径 |
| --- | --- |
| API Key | 运行时详情页 → 单击 URN → 进入工作负载身份详情页 → 复制 API Key 值。**API Key 由凭据管理服务（DEW）托管，托管按需计费** |
| IAM | 使用 AK/SK 签名调用 |
| OAuth 2.0 | 第三方身份提供商签发 JWT |

> 费用提示：**Managed Agents 如果选择 API Key 认证，则创建后即开始计费。**

### 6.3 执行流程

1. **沙箱配置**：沙箱按环境配置完成构建
2. **智能体循环执行**：Managed Agents 根据消息自主决策需要调用的工具
3. **工具执行**：所有文件写入、bash 命令执行及其余工具调用都在沙箱环境中运行
4. **流式事件推送**：任务执行过程中实时推送状态更新
5. **转为空闲状态**：没有待执行任务时触发

### 6.4 流式帧格式

```json
{"response_kind":"e2a.chunk","status":"in_progress","body":{"delta_kind":"text","delta":"你好","event_type":"chat.delta"}}
{"response_kind":"e2a.complete","status":"succeeded","is_final":true,"body":{"result":{"content":"你好！有什么可以帮你的吗？"}}}
```

工具权限审批单独成帧：

```json
{"tag":"TOOL_PERMISSION","decision":"ASK","tool":"write_file","rule":"allow_write","source":"system"}
```

> 权限审批和用户提问均在后台自动处理，终端只显示 `Frame` 原始帧与流式回复文本。

### 6.5 多会话与并发

每次调用通过会话 ID 隔离上下文，支持同一智能体被多用户并发调用且互不干扰。会话 ID 由调用方**自行生成**，英文/数字/`-`/`_`，≤ 64 字符（如 `123e4567e89b12d3a456426614174000`）。

## 7. 与运行时的选型

| 判据 | 选 Managed Agents | 选运行时 |
| --- | --- | --- |
| 上手方式 | 配置驱动，零代码 | 代码驱动，打包镜像 |
| 基础设施 | 全托管 | 用户管理版本/实例 |
| 定制灵活度 | 通过配置项调整 | 代码层面完全可控 |
| 适用场景 | 快速验证 / 标准场景 | 深度定制 / 复杂逻辑 |
| 需要 Skill | ✅（须私网 + OBS） | 不适用（技能在代码里） |
| 需要自定义依赖/中间件 | ❌ | ✅ |
| 需要 MCP 入站协议 | ❌（仅 WebSocket 调用面） | ✅（HTTP + MCP） |
| 计费起点 | API Key 认证下创建即计费 | 按运行时资源/调用 |

## 8. 常见问题（官方）

| 问题 | 结论 |
| --- | --- |
| 环境被智能体关联后能否修改 | **不能**。需先解绑或新建环境 |
| 会话空闲超时 与 最大存活时间 的区别 | 空闲超时看"无交互时长"，最大存活时间看"从创建起的绝对时长"。两者**任一满足即终止** |
| 会话存储 / SFS Turbo / OBS 的区别 | 见 3.2 对比表 |
| 会话超时后数据还在吗 | 会话存储中的数据按挂载路径保留；**沙箱内本地磁盘数据全部丢失** |
| 存储挂载路径约束 | 不能含 `..`；须为 `/home`、`/mnt`、`/data`、`/tmp` 子目录；多个挂载禁止相同或包含关系 |
