# Knowledge Base（知识库 / RAG 底座）

> 事实来源：`AgentArts原始材料-0916/智果（AgentArts）智能体平台 托管与运行智能体.pdf` 第 9 章（309–382 页）；`常见问题.pdf` 第 7 章。
>
> **知识库是 0916 材料新增的独立能力域**，0804 材料中不存在。它与记忆库是两条互补的数据通路。

## 1. 定位：知识与记忆的分工

| 对比项 | 知识库 | 记忆库 |
| --- | --- | --- |
| 存储内容 | 预先准备的**静态知识**（文档、FAQ、手册） | 交互产生的**动态信息**（对话、偏好、经验） |
| 数据来源 | 人工导入、系统同步或外部数据源接入 | Agent 与用户/环境持续交互过程中产生 |
| 更新方式 | 按文档或数据源新增、更新、删除、重建索引 | 持续增量更新，可新增、修改、删除 |
| 检索时机 | 用户提问时检索相关段落 | 对话过程中按业务需求检索相关记忆 |
| 典型场景 | RAG、知识问答、文档检索 | 用户偏好、历史决策、经验复用 |
| 举例 | 产品使用说明书 | 用户偏好咖啡加冰 |

一句话：**知识库解决"Agent 知道什么"，记忆库解决"Agent 记得什么"。**

## 2. 知识库类型

AgentArts 支持两类知识库：

| 对比维度 | 平台知识库 | 第三方知识库 |
| --- | --- | --- |
| 定义 | 在 AgentArts 内直接创建并管理 | 将第三方系统中的知识库接入 AgentArts |
| 数据存储 | 存储在 AgentArts 平台 | 存储在第三方系统，**数据不传入平台** |
| 使用场景 | 无现成知识库，需上传文档管理 | 已有企业知识库，希望直接对接 |
| 配置难度 | 低（上传即用） | 中（需配置连接参数） |
| 计费 | 占用套餐包存储额度 | AgentArts 侧免费，第三方侧费用自理 |
| 检索路径 | 平台内部向量化检索 | 平台将检索请求发送至第三方知识库接口，取回结果 |

### 2.1 第三方知识库三种类型

| 类型 | 说明 | 接入方式 | 复杂度 |
| --- | --- | --- | --- |
| **General** | 通用外部知识库。适用于自研知识库或非标准接口系统 | 需先按《第三方通用知识库接入规范》适配开发，再接入 | 中 |
| **KooSearch** | 直接接入 KooSearch 知识库 | 直接接入，零代码 | 低 |
| **RAGFlow** | 直接接入 RAGFlow 知识库 | 直接接入，零代码 | 低 |

> 第三方知识库均支持"命中测试"；General 类型额外要求遵循《第三方通用知识库接入规范》（托管与运行智能体 9.5.6）。

## 3. 支持的文档格式

| 文档类型 | 格式及限制 |
| --- | --- |
| **知识文档** | 文档/文本类：`doc`、`docx`、`pdf`、`ofd`、`txt`、`md`、`wps`<br>表格/数据类：`xls`、`xlsx`、`csv`、`et`<br>演示/幻灯片类：`ppt`、`pptx`、`dps`<br>图片/设计类：`jpg`、`jpeg`、`png`、`gif`、`bmp`、`webp`、`tiff`、`tif`、`psd`、`ico`、`pcx` |
| **FAQ** | 仅支持按模板上传：`xlsx`、`xls`、`docx`、`doc`；**Excel 单文件 ≤ 100,000 条**；文件中**不允许空行，空行后的数据将被忽略** |

图片类文件支持两种处理：**直接存储图片** 或 **提取图片中的文字信息存储**。

## 4. 使用限制（按套餐）

| 资源 | 体验版 | 团队标准版 | 团队高级版 | 企业专业版 | 企业旗舰版 |
| --- | --- | --- | --- | --- | --- |
| 知识库数量（单租户） | 5 | 10 | 20 | 50 | — |
| 上传文档/FAQ 单文件大小 | 20MB | 60MB | 60MB | 60MB | 60MB |
| OBS 接入文件单文件大小 | 20MB | 128MB | 128MB | 128MB | 128MB |
| 知识库容量 | 1GB | 5GB | 50GB | 200GB | 1200GB |
| 召回数量（最大文本切片数） | 50 | 50 | 50 | 50 | 50 |

- **召回**：从知识库中检索并返回相关内容片段的过程
- **文本切片**：系统将文档自动切分成的片段，检索时按片返回
- 达到限制时相关操作失败并提示；体验版单智能体/工作流**仅支持关联 1 个知识库**

> ⚠️ **官方文档冲突待澄清**：`计费说明.pdf`（版本 04）的知识库空间为 **1GB / 4GB / 40GB / 200GB / 800GB**，与上表（托管与运行智能体，版本 01）不一致。以采购合同/控制台实际展示为准，本表按《托管与运行智能体》记录。

## 5. 检索增强能力

知识库为**应用**与**工作流**提供检索增强能力：

- **在单智能体中使用知识库**（托管与运行智能体 9.6.1）
- **在工作流中使用知识库**（9.6.2）

> 常见问题：单智能体与工作流应用中的知识库检索策略不一致（`常见问题.pdf` 1.9），设计时需分别确认检索参数，不能假设两者等价。

## 6. 主要操作路径

| 操作 | 说明 |
| --- | --- |
| 创建知识库 | 配置模型、解析配置、拆分配置 |
| 上传文档 | 支持知识文档与 FAQ 模板文件 |
| 知识库分段 | 为知识库设置"拆分配置"，决定文本如何切片；支持规则解析 |
| 命中测试 | 验证检索效果（平台知识库与第三方知识库均支持） |
| 接入第三方知识库 | General / KooSearch / RAGFlow 三种 |
| 管理知识库 | 列表与详情管理、维护 |

## 7. 与记忆库的协同设计建议

| 场景 | 知识库 | 记忆库 |
| --- | --- | --- |
| 企业知识问答（RAG） | ✅ 主通路 | ○ 可选（记住用户偏好） |
| 智能客服 | ✅ 产品手册、FAQ | ✅ 用户历史咨询与偏好 |
| 个人助手 | ○ 可选（领域资料） | ✅ 主通路 |
| 长任务智能体 | ○ 可选 | ✅ 阶段性信息延续 |

**边界原则**：知识库承载**可共享、相对静态、面向全体用户**的内容；记忆库承载**按 `actor_id` 隔离、动态积累、面向个体**的内容。不要把用户隐私数据放进知识库——知识库可被多个 Agent 共享。
