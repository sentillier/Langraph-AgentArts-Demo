# 架构图绘图 Prompt（gpt-image-2）

> 配套文档：[整体架构设计v3.md](整体架构设计v3.md)（§3.1 架构总图、§3.3 数据流、§3.4 范式选型、**§4.9 智能体安全**）。
>
> **模板选择**：`infographic-engine`（Charts & Infographics / Scenes: Tech, Education；示例用例 case 334 / case 1 / case 8）。备选：`document-publishing`（用于需要"图册/白皮书版式"的分层总图）。

## 0. 使用说明

| 项 | 说明 |
|---|---|
| 为什么拆 4 张 | 0916 能力域从 4 个扩到 8 个（新增**智能体安全**）+ 三层身份 + 存储 + 治理。塞进一张会触发 `infographic-engine` 的核心坑位：**模块数过多 → 标签乱码、文字压字、层级塌陷**。官方模板建议单图 3–5 个模块块；本方案每张控制在 5–7 个板块。 |
| 四张图的分工 | 图 1 = **静态能力全景**（分层）；图 2 = **动态一次调用**（数据流）；图 3 = **选型决策**（决策树）；图 4 = **智能体安全三层防护**（安全专项，含"已确认 / 待补充"视觉区分）。四张共用同一套配色与图例，可拼成一组。 |
| 中文渲染提醒 | gpt-image-2 对中文长标签不稳定。**铁律**：主标题用中文，模块标签用「中文主标签 + 英文小字副标签」，单个中文标签 ≤ 12 字，严禁在画面里放成段文字。若生成后中文有错字，把该图 prompt 里的中文标注改为纯英文重生成。 |
| 建议尺寸 | 图 1：16:9（横向分层，信息密度最高）；图 2：16:9；图 3：4:3；图 4：4:3。 |
| 迭代方式 | 每次只改一个变量（配色 / 布局 / 文字密度），保留上一版对比。 |

## 1. 全局视觉规范（四张图共用，保证成套）

```text
【统一视觉规范】
- 类型：清洁扁平矢量信息图（clean flat vector infographic），企业级技术方案文档风。
- 背景：浅灰白 #F5F7FA；四个角留 8% 安全边距；无纹理、无水印。
- 形状：圆角矩形（8px 圆角）、1px 描边；层级内部用纯色块区分，不用阴影、不用渐变、不用发光。
- 主色：华为云红 #C7000B（仅用于"运行时"与主标题强调）、深蓝 #1B2A47（文字与入站/边界带）、中性灰 #8C99A8（辅助文字与外部能力描边）。
- 能力域配色：7 种低饱和浅色，色相一致、明度接近（浅蓝 / 浅青 / 浅绿 / 浅紫 / 浅橙 / 浅粉 / 浅灰蓝），每类能力域固定一色，三张图保持同一映射。
- 安全能力固定用**深青绿 #1F6F6B**（与七大能力域色系区分），且**待补充能力一律用虚线边框 + 中性灰**表示。
- 连线：调用/数据流用实线箭头；控制面/管理流用虚线箭头；日志与指标回流用最细的浅灰虚线箭头。
- 禁止：3D 立体、isometric 等距、写实插画、照片、人物、装饰性图形、超过 6 种主色。
```

- 第 3 层 → 第 4 层 → 第 5 层：细实线箭头，表示调用能力。

## 5. 图 4：智能体安全三层防护图
